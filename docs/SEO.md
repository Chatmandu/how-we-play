# SEO implementation notes

## Delivered

- **Static HTML for all core content.** Every page is pre-rendered; diagrams are inline SVG with `<title>` and `<desc>` written from the content's `caption` and `altSummary`. All diagram variants (wrong, right, stages) are in the HTML as tab panels; JavaScript only enhances them.
- **Conventional URLs** with trailing slashes: `/formations/9v9/`, `/formations/9v9/3-1-3-1/`, `/formations/9v9/3-1-3-1/one-goes-one-stays/`, `/formations/9v9/3-1-3-1/positions/screen/`, `/moving-up/`, `/about/`.
- **Per-page metadata** (`src/layouts/Base.astro`): `<title>`, meta description, canonical (`https://howweplayfootball.com` + path, regardless of host, so pages.dev previews never compete), `robots`, Open Graph (`og:title`, `og:description`, `og:url`, `og:type`, `og:image` 1200 × 630, `og:locale en_GB`), `twitter:card`.
- **Structured data (JSON-LD):** `WebSite` and `Organization` on the homepage; `BreadcrumbList` on every inner page; `Article` on formation guides and lessons. FAQ and HowTo markup deliberately not used.
- **Breadcrumbs** visible on every inner page and matching the URL path.
- **Headings:** exactly one `<h1>` per page (enforced by the build check); sections use `h2`/`h3`. Headings are written in sentence case and styled in capitals, so the text search engines and screen readers get is normal case.
- **Sitemap and robots:** generated by `scripts/check-build.mjs` after each build. Public: `sitemap.xml` lists only indexable pages (today: `/`, `/formations/9v9/`, `/moving-up/`, `/about/`), `robots.txt` allows all and points to the sitemap. Preview: no sitemap, `robots.txt` disallows all, `noindex` meta and `X-Robots-Tag` header on every response.
- **Language and locale:** `<html lang="en-GB">`, UK spelling.
- **Performance:** no client framework; one small module (design-system behaviours plus renderer) per page; two self-hosted WOFF2 font families with the display 900 and sans 400 weights preloaded; long-cache headers for `/_astro/*` and `/fonts/*`.
